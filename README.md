# FinSight — Corporate Financial Intelligence Platform

FinSight is a professional corporate financial intelligence and sentiment advisory platform. It integrates live market data, financial statement analysis, news sentiment analytics, and AI-driven advisory summaries into a clean, glassmorphic Streamlit dashboard designed for retail investors and junior financial analysts.

---

## Key Features

1. **Executive Dashboard (`pages/dashboard.py`):**
   * Displays exchange, real-time price info, price changes, market cap, key ratios (P/E, ROE), risk levels, and an AI company summary in a single unified view.
   * Houses an underlying execution status telemetry pipeline showing real-time stage completion.

2. **Interactive Price Charts (`pages/1_Price_Chart.py`):**
   * Dynamic Plotly area charts matching performance color schemes (green for positive period changes, red for negative).
   * Interactive timeframe selection (e.g. 1 Month, 3 Months, 6 Months, 1 Year, 2 Years, 5 Years).

3. **Financial Ratios Scorecard (`pages/2_Financial_Ratios.py`):**
   * Key valuation metrics (P/E Ratio, P/B Ratio) and profitability/return metrics (Return on Equity, Net Profit Margin, Dividend Yield, and EPS).

4. **News & Sentiment Analysis (`pages/3_News_&_Sentiment.py`):**
   * Pulls news headlines and summaries dynamically from yfinance news feeds.
   * Performs advanced tokenization and text preparation using **NLTK** (removing stopwords and punctuation) followed by sentiment polarity classification using **TextBlob** (-1.0 to +1.0 score mapped to *Positive*, *Neutral*, or *Negative*).

5. **Investment Risk Scorecard (`pages/4_Risk_Assessment.py`):**
   * Analyzes corporate leverage, liquidity, profitability, and news sentiment coverage using a transparent rules engine to classify tickers as *Low*, *Moderate*, or *High* risk.

6. **AI Advisory Briefing (`pages/5_AI_Summary.py`):**
   * Distills parsed company profiles, balance sheet ratios, news sentiment, and risk ratings into a structured AI briefing report (Executive Summary, Investment Thesis, Strengths, and Weaknesses) generated by the **Google Gemini 2.5 Flash API**.
   * Strictly adheres to educational and non-financial advice disclaimers.

---

## Technical Stack & Libraries
* **Language:** Python 3.12+
* **Frontend UI:** Streamlit (Clean, border-accented white cards)
* **Data Provider:** yfinance (Yahoo Finance API client wrapper)
* **Interactive Charts:** Plotly (Area and indicator gauge visualization)
* **NLP & Text Analytics:** NLTK (Tokenization & preprocessing) + TextBlob (Lexicon sentiment polarity scoring)
* **AI Engine:** Google Gemini 2.5 Flash API (REST client implementation with dynamic mock fallback mode)

## Setup & Running Guide

### 1. Prerequisites
* Python 3.12 or higher
* Conda Package Manager (highly recommended)

### 2. Environment Activation & Dependencies Installation
First, activate your Conda environment (e.g. `finsight`) and install all required python dependencies:
```bash
conda activate finsight
pip install -r requirements.txt
```

### 3. Environment Configuration
Create a `.env` file in the root directory:
```env
# FinSight Settings
APP_ENV=development
DEBUG=True
LOG_LEVEL=INFO

# API Keys
GEMINI_API_KEY="your_google_gemini_api_key"
GEMINI_MODEL="gemini-2.5-flash-lite"
```
*Note: If no `GEMINI_API_KEY` is supplied (or left empty), the application dynamically shifts into a high-fidelity mock fallback generator for summary generation.*

### 4. Run the Streamlit Application
Run the main Streamlit application entry point from the project root:
```bash
streamlit run app.py
```

### 5. Run the Unit Test Suite
To verify the entire analytical pipeline, run the Python unittest suite:
```bash
python -m unittest discover tests
```

## Architectural Principles
FinSight is built upon a **Clean Architecture / N-Tier Architecture** pattern ensuring high decoupling and testability:
1. **Model Decoupling:** Data structures in `models/` contain only basic data structures and no business logic.
2. **UI Separation:** Modules in `services/` and `models/` have zero dependencies on presentation libraries like `streamlit`. 
3. **Robust Error Propagation:** Exceptions are safely caught, mapped to custom domain exceptions, and handled by presentation layers using banners (`components/errors.py`) rather than allowing raw stack traces to crash pages.
